ЧЕРТЕЖИ ЕСКД • Windows 10/11 x64

1. Распакуйте ZIP целиком в удобную папку. Запустите «Чертежи ЕСКД.exe». Рядом должны находиться папки app и runtime. Python, библиотеки PDF и графический интерфейс включены. Модель запускается вашим API-сервером.

2. Выберите папку с исходными PDF и отдельную папку вывода. Вход проверяется со всеми подпапками. Папки не должны быть вложены одна в другую. Удобно выделить пустую папку вывода на один архив. Пример: G:\ai\архив и G:\ai\результат.

3. Выберите провайдера, проверьте URL, укажите имя визуальной модели в точности как на сервере. При необходимости введите ключ. Базовый URL и ключ можно вставить из буфера сочетанием Ctrl+V или кнопкой «Вставить» рядом с полем. Кнопка заменяет содержимое поля. Примеры базовых адресов:
   Ollama         http://127.0.0.1:11434/v1     модель qwen2.5vl:7b
   LM Studio      http://127.0.0.1:1234/v1      ID загруженной визуальной модели
   LiteLLM Proxy  http://127.0.0.1:4000/v1      имя маршрута из конфигурации прокси
   OpenAI API     https://api.openai.com/v1     доступная вашему ключу модель с изображениями
   Другой API     ваш базовый адрес или полный путь до /chat/completions
   Для локальной Ollama установите и запустите Ollama, затем один раз выполните в PowerShell:
       ollama pull qwen2.5vl:7b
   Провайдер должен принимать Chat Completions с изображениями PNG в data URL и возвращать текстовый JSON. LiteLLM передаёт запросы модели, назначенной вашему маршруту. Для работы на своём ПК используйте локальный сервер и модель. При выборе удалённого сервера на указанный адрес уходят изображения страниц и штампов. Имена файлов и их пути в запрос не включаются. Ключ действует до закрытия окна. Остальные настройки сохраняются в %LOCALAPPDATA%\EskdDrawingReview.

4. Нажмите «Проверить API». Проверка использует маленькое тестовое изображение. Затем нажмите «Обработать и сшить». Сначала удобно выбрать небольшую папку с известными чертежами. В обработке по два запроса на успешно локализованную страницу: поиск штампа и чтение его полей. Время зависит от модели, размера архива и видеокарты. Закрытый процесс можно запустить снова с теми же настройками. Успешные результаты хранятся постранично, ошибки чтения программа пробует обработать повторно. Изменение файла, модели или адреса создаёт новые результаты. Если веса модели заменили под прежним именем, используйте новую папку вывода для полного пересчёта.

5. После обработки программа сохраняет каждый полный комплект одним PDF непосредственно в выбранной папке вывода. Имя PDF включает обозначение и короткий идентификатор для различения похожих имён в Windows. Кнопка «Открыть результат» открывает эту папку. Если исходники уже распознаны и с тех пор не менялись, кнопка «Сшить из реестра» соберёт PDF по сохранённым данным без обращения к API. Откройте «Отчёт.txt»: для каждого обозначения перечислены число файлов, ожидаемое количество, найденные листы, пропуски, причины ошибок, исходные пути, страницы и имя готового PDF. При отсутствии первого листа пропуски известны только до максимального найденного номера.

   «Страницы.csv» и «Комплекты.csv» открываются в Excel (UTF-8, разделитель — точка с запятой). Таблицы для просмотра. Решения проверяющего вводятся через окно программы. Закрывайте открытые CSV перед повторной обработкой, если Excel заблокировал запись.

6. В списке страниц для проверки отметьте галочками строки, где указаны верные обозначение, номер листа и количество листов. Нажмите «Подтвердить отмеченные». Программа сохранит показанные значения, пересчитает комплектность и соберёт готовые PDF.

   Двойным щелчком откройте карточку страницы, чтобы посмотреть штамп или исправить поля. Введите точное обозначение и номер листа, для первого также количество листов. Укажите основание и нажмите «Подтвердить». Если две разные страницы претендуют на один номер, исключите лишнюю с пояснением. Флажок «Показать все страницы» позволяет пересмотреть любое решение, в том числе исключение. При появлении отсутствующего файла добавьте его к источникам и нажмите «Обработать и сшить». После перезапуска «Открыть реестр» покажет сохранённые результаты без вызова модели.

7. Правила сборки. Основание — полное обозначение и номера из видимого штампа. Имя с (2) проверяется отдельно. Страница PDF и лист чертежа учитываются отдельно. Если графа «Лист» явно пуста, а в «Листов» указано 1, программа считает лист первым для чертежа с полной формой или спецификации. Страницы автоматически проходят при согласованных полях, имени и комплектности. Для листов с прочитанным номером тип штампа приводится в отчёте для справки. Для программного PDF программа дополнительно проверяет присутствие прочитанного обозначения в доступном текстовом слое фрагмента при стандартной ориентации. Для сканов встроенный распознаватель — визуальная модель. Автоматическая проверка не гарантирует безошибочное OCR: проверьте на своих примерах, особенно близкие по виду буквы и цифры.

   Программа копирует исходные страницы по номерам от 1 до N, после записи сверяет количество, размеры и контрольное изображение каждой страницы. Разные варианты одного листа, неизвестный итог, выход за диапазон, расходящиеся имена и неразборчивые штампы оставляют комплект на проверке. Один полностью нечитаемый файл относится к кандидату по имени. При совершенно неверном имени установить его принадлежность автоматически невозможно.

   Папка .eskd содержит реестр SQLite, изображения штампов, состав сборок и архив предыдущих версий. Сохраните её для возобновления и проверки истории. При изменении результата предыдущие PDF, созданные этой программой и совпадающие с её контрольной суммой, перемещаются в .eskd\предыдущие. Посторонние или отредактированные вручную PDF программа оставляет на месте. Имена актуальных комплектов всегда приведены в «Отчёт.txt».
